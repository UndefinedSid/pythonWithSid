# pythonWithSid

A structured collection of Python programming concepts, projects, and experimental scripts, ranging from core fundamentals to advanced implementations like OOPs, decorators, and AI integrations.

---

## 📁 Repository Structure

### 🔹 Core Python & Fundamentals
* **`01_basic`**: Introduction to Python syntax and fundamental concepts.
* **`condAndLoop`**: Practices and examples covering conditional statements (`if-else`) and loops (`for`, `while`).
* **`dictionary`**: Deep dive into Python dictionaries, mapping, and key-value pair manipulations.
* **`errorHandle.py`**: Implementation of exception handling using `try-except-finally` blocks.
* **`ques1.py` & `ques2.py`**: Problem-solving scripts and practice exercises.

### 🔹 Advanced Concepts
* **`OOPs`**: Object-Oriented Programming principles including Classes, Inheritance, Polymorphism, and Encapsulation.
* **`decorators`**: Advanced functions, wrappers, and closure implementations in Python.

### 🔹 Data Science & AI
* **`numpy`**: Arrays, mathematical operations, and data manipulation using the NumPy library.
* **`openai_api`**: Scripts interacting with OpenAI's API for AI-powered applications.

### 🔹 Projects & Database Management
* **`proj_sqlite`**: Local database storage and management using SQLite3.
* **`project@yt`**: YouTube-related project or automation script.

### 🔹 Environment Configurations
* **`VirEnv_jupyter` / `virtualEnvor`**: Configurations and guides for setting up virtual environments and Jupyter Notebook kernels.
* **`.gitignore`**: Specifying untracked files that Git should ignore.
